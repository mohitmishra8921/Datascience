## 📖 About This Repository

This is my **core Data Science workspace** — where I practice the full exploratory data analysis (EDA) pipeline on real and sample datasets: collecting data, cleaning it, filtering it, and visualizing it to extract insight.

This repo represents the foundation of my data science skill set — the same workflow every real-world data project starts with.

---

## 🧩 Notebooks Overview

| Notebook | What It Covers |
|:---|:---|
| `Data_collection_techniques.ipynb` | Methods and strategies for gathering raw data before analysis |
| `Data cleaning.ipynb` | Handling missing values, duplicates, and inconsistent data — turning raw data into usable data |
| `Datafiltering_filtering.ipynb` | Filtering, subsetting, and querying datasets based on conditions |
| `Broadcasting_vectorisation.ipynb` | NumPy broadcasting and vectorized operations for fast, efficient computation |
| `Basic_matplotlib.ipynb` | Data visualization fundamentals — plots, charts, and figure customization |

> This repo is a living workspace — notebooks are added as I explore new EDA and visualization techniques.

## 🚀 How to Run

1. Clone the repo:
```bash
   git clone https://github.com/mohitmishra8921/Datascience.git
```
2. Install the required libraries:
```bash
   pip install pandas numpy matplotlib openpyxl jupyter
```
3. Launch Jupyter and open any notebook:
```bash
   jupyter notebook
```
